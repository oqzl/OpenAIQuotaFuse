# Local Codex marketplace metadata

`marketplace.json` lets current Codex CLI versions register this repository directly as a plugin marketplace.

    codex plugin marketplace add oqzl/OpenAIQuotaFuse
    codex plugin add openai-quota-fuse@openai-quota-fuse

The manual personal-marketplace fallback remains documented in `docs/CODEX_PLUGIN.md` and `docs-ja/CODEX_PLUGIN.md`.
